# Remotion Video Project (Rendered with GitHub Actions)

Repositori ini berisi kumpulan video Remotion yang di-render secara otomatis di cloud menggunakan **GitHub Actions** (RAM 7 GB, 60 FPS).

## 📁 Daftar Video Hasil Render (Folder `result/`)

### 1. `result/video1.mp4`
- **Judul**: *TAUKAH KAMU? Sistem Perang Modern Masa Kini*
- **Format**: Vertikal 1080 × 1920 (9:16), 60 FPS (1.850 Frame)
- **Topik**: Drone intai, Satelit & Radar Phased Array, C4ISR tactical network, sistem pertahanan udara otomatis, dan jet siluman Gen-5.

### 2. `result/video2.mp4`
- **Judul**: *Cara Install Remotion + AI Skill | Bikin Video Otomatis Pakai Gemini!*
- **Format**: Vertikal 1080 × 1920 (9:16), 60 FPS (4.730 Frame)
- **Materi**: Tutorial lengkap developer 7 langkah dengan standar antislop & UI/UX Pro Max serta suara narator manusiawi alami.

### 3. `result/video3.mp4`
- **Judul**: *Animasi Perkembangan GDP Ekonomi Dunia (1950–2026)*
- **Format**: Vertikal 1080 × 1920 (9:16 TikTok / Reels / Shorts), 60 FPS Murni (3.300 Frame / 55 Detik)
- **Fitur**:
  - Bar Chart Race interaktif 10 besar ekonomi dunia dari tahun 1950 sampai 2026.
  - Perhitungan interpolasi linear tahunan yang mulus.
  - Penanda peristiwa sejarah ekonomi penting (*economic milestones*): lonjakan Jepang pascaperang, runtuhnya Uni Soviet, lonjakan manufaktur China, dan naiknya India ke 5 besar.
  - Voiceover intro bahasa Indonesia + rhythmic data-viz beat.
